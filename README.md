# Higgsfield source for Grayjay

An experimental source for public Higgsfield community films. It reads the contest catalog, searches for films, and resolves playable media from public project links. It is independent of Higgsfield and FUTO.

In Grayjay, open Sources, choose Add Source, and enter this manifest URL.

```
https://raw.githubusercontent.com/jlmalone/grayjay-plugin-higgsfield/master/HiggsfieldConfig.json
```

Review the signed script and the three Higgsfield hosts listed in the manifest. The first release uses Grayjay’s video and stream types. It needs an Android Grayjay install and playback check. Provider page changes can affect playback and search.
